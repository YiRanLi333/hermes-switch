# Contributing

Thanks for helping improve Hermes Switch.

## Development

Run the tests before submitting changes:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\hermes-switch.test.ps1
```

## Guidelines

- Do not commit real API keys or private config files.
- Keep PowerShell compatible with Windows PowerShell 5.1 when possible.
- Prefer clear terminal output over clever formatting.
- Add or update tests for behavior changes.
